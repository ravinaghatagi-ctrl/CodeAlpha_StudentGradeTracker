# CodeAlpha_StudentGradeTracker

Student Grade Tracker is a Java-based application used to manage student grades and calculate important statistics.

## Features

* Add student grades
* Store student information
* Calculate average marks
* Find highest marks
* Find lowest marks
* Display a summary report

## Technologies Used

* Java
* ArrayList
* Object-Oriented Programming

## How to Run

1. Install Java JDK.
2. Open the project in VS Code or IntelliJ IDEA.
3. Compile the Java program.
4. Run the program.
5. Enter the student details and grades.

This project was developed as part of my CodeAlpha internship to practice Java programming, data structures, and basic application development.
